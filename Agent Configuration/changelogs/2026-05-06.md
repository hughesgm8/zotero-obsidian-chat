## [~12:00] Add GitHub Models and Gemini as LLM providers (v0.3.0)

- **Files Modified**: `src/llm/github-models.ts` (new), `src/llm/gemini.ts` (new), `src/llm/index.ts`, `src/types.ts`, `src/settings.ts`, `manifest.json`, `package.json`
- **Change**: Added two new cloud LLM providers — GitHub Models (free, uses a GitHub PAT) and Google Gemini (free tier, large context via Google AI Studio key). Both appear in the provider dropdown in settings alongside the existing Ollama, OpenRouter, and Anthropic options.
- **Logic Update**:
  ```
  # New providers follow the same pattern as existing ones:
  LLMProviderType += "github-models" | "gemini"
  ZoteroMCPSettings += githubModelsApiKey, githubModelsModel, geminiApiKey, geminiModel
  createLLMProvider() factory handles both new cases
  Settings UI shows token/key + model fields conditionally per provider
  Both use https streaming (Node http module, SSE) for large context handling
  GitHub Models endpoint: models.github.ai/inference/chat/completions
  Gemini endpoint: generativelanguage.googleapis.com/v1beta/openai/chat/completions
  ```
- **Reason**: Ollama cloud relay and OpenRouter free tier now require paid subscriptions. GitHub Models offers free DeepSeek access; Gemini offers a free tier with a 1M-token context window (important for full research paper processing). GitHub Models has an ~8k token input cap on the free tier, making it unsuitable for papers — Gemini 2.0 Flash is the recommended default.
